# AI Career Platform

An AI-assisted career preparation platform that helps users compare a resume with a job description, identify skill gaps, and practice interviews. It combines a React frontend with a FastAPI backend and MongoDB for user and analysis data.

## Features

- Resume and job-description analysis with extracted and normalized skills
- Hybrid matching score combining weighted skill overlap, category overlap, TF-IDF similarity, and semantic similarity
- Matched and missing skill lists, score breakdown, and readiness summary
- Learning recommendations, learning plans, and tutorial resources for skill gaps
- Score simulation showing estimated impact from addressing missing skills
- Role-based and resume-based interview practice with answer evaluation and reports
- User authentication and per-user usage limits

## Technology Stack

- **Frontend:** React, Vite, React Router, Tailwind CSS, Axios
- **Backend:** Python, FastAPI, Pydantic
- **Database:** MongoDB with Motor (asynchronous Python driver)
- **Resume matching:** scikit-learn TF-IDF and Sentence Transformers (`all-MiniLM-L6-v2`)
- **Integrations:** Gemini, OpenRouter, and YouTube Data API

## Requirements

- Python 3.11 or newer
- Node.js and npm
- MongoDB, locally or through MongoDB Atlas

## Run Locally

### 1. Configure the backend

In PowerShell, from the repository root:

```powershell
Copy-Item backend/.env.example backend/.env
```

Edit `backend/.env` and set `JWT_SECRET_KEY` to a random value at least 32 characters long. For example, generate one with:

```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```

Set `MONGODB_URL` to your MongoDB connection string. MongoDB must be running and reachable when the backend starts. Add valid provider API keys in the appropriate configuration if you plan to use the related AI and video features. Never commit `.env` files or API keys.

### 2. Install and start the backend

```powershell
Set-Location backend
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

The API runs at `http://localhost:8000`. Interactive API documentation is at `http://localhost:8000/docs`, and the health endpoint is `http://localhost:8000/health`.

### 3. Install and start the frontend

Open a second terminal from the repository root:

```powershell
Set-Location frontend
npm install
npm run dev
```

Vite prints the local frontend URL, normally `http://localhost:5173`. The frontend defaults to the backend at `http://localhost:8000`. To change that, set `VITE_API_URL` in a frontend `.env` file.

## Resume Matching Overview

The matching system combines four signals:

- **Weighted skill overlap:** matches normalized resume skills against job-description skills, with higher weights for selected skill categories.
- **Category overlap:** compares the categories represented by the resume and job description.
- **TF-IDF similarity:** measures overlap in important terms across the resume text and job description.
- **Semantic similarity:** compares text embeddings generated by `all-MiniLM-L6-v2`.

The final score uses the weights implemented in the backend:

```text
0.30 × weighted skill score
+ 0.20 × category overlap score
+ 0.25 × TF-IDF similarity
+ 0.25 × semantic similarity
```

The result is a readiness estimate, not a hiring decision or guarantee of employment. Resume formatting and skill vocabulary can affect extraction and matching results.

## Configuration and Security Notes

- Keep secrets in local environment/configuration files and out of source control.
- Use a strong, unique `JWT_SECRET_KEY`; the backend rejects missing or weak values.
- Configure the allowed frontend origins with `FRONTEND_URLS` when accessing the API from a different host.
- Resume and job-description analysis may send text to configured external AI services. Do not upload sensitive documents unless you are comfortable with the configured data handling and provider policies.
